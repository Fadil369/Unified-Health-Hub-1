## Complete Replit Build Prompt: iOS & Android Mobile App

> **Stack**: React Native + Expo | **Target**: iOS & Android | **Platform**: Replit  
> **Domain**: NPHIES-Aligned Saudi Healthcare Insurance | **Region**: Saudi Arabia → MENA → Global

-----

## 📋 PROJECT OVERVIEW

Build **BrainSAIT Ultimate** — a production-grade, bilingual (Arabic/English) mobile healthcare insurance platform for Saudi Arabia. This app serves as the citizen-facing interface to the NPHIES (National Platform for Health Information Exchange Services) backend, aligned with Saudi Vision 2030.

The app must handle real-time insurance eligibility checks, prior authorization, claims management, digital health wallet, AI-powered decision support, and full FHIR R4 compliance — all within a beautiful, glass-morphism UI with RTL/LTR adaptive layouts.

## 🏗️ TECHNICAL STACK

### Mobile Framework

```
Framework:        React Native 0.73+ with Expo SDK 50+
Language:         TypeScript (strict mode, no any)
State Management: Zustand + React Query (TanStack Query v5)
Navigation:       Expo Router (file-based routing)
UI Library:       NativeWind (Tailwind for React Native) + custom components
Animations:       React Native Reanimated 3 + Lottie
Forms:            React Hook Form + Zod validation
```

### Backend Integration

```
API Layer:        FHIR R4 REST endpoints (existing Go microservices)
Real-time:        WebSocket + Apache Kafka consumer bridge
Auth:             OAuth2 + OIDC (JWT tokens, Absher/eID ready)
Offline:          WatermelonDB for local FHIR resource caching
Push:             Expo Notifications (APNs + FCM)
```

### Security & Compliance

```
Encryption:       AES-256 at rest, TLS 1.3 in transit
Biometrics:       expo-local-authentication (Face ID / fingerprint)
Storage:          expo-secure-store for PHI/tokens
Audit:            Every PHI access logged with timestamp + user + action
Compliance:       HIPAA, PDPL (Saudi), NPHIES standards
```

### AI/ML Integration

```
LLM:              Claude claude-sonnet-4-20250514 via Anthropic API
Agents:           MASTERLINC, HEALTHCARELINC, CLINICALLINC, COMPLIANCELINC
Voice:            expo-speech + Web Speech API bridge
Language:         Arabic (primary) + English bilingual
```

## 🔒 SECURITY IMPLEMENTATION

```typescript
// PHI Data Handling Rules:
1. Never log PHI to console in production
2. Mask PHI in error messages (show last 4 digits max)
3. Store all tokens in expo-secure-store (not AsyncStorage)
4. Clear PHI from memory on app background
5. Certificate pinning for API connections
6. Jailbreak/root detection using expo-device
7. Screenshot prevention on sensitive screens
8. Biometric re-authentication for wallet/documents

// Audit Log Schema (every PHI access):
interface AuditEvent {
  eventId: string;           // UUID
  timestamp: string;         // ISO 8601
  userId: string;            // Authenticated user
  userRole: string;          // patient|provider|admin
  action: string;            // VIEW|CREATE|UPDATE|DELETE
  resourceType: string;      // FHIR resource type
  resourceId: string;        // Resource ID (masked if needed)
  outcome: string;           // success|failure|error
  deviceId: string;          // Hashed device identifier
  ipAddress: string;         // Client IP
  sessionId: string;         // Current session
}
```

```
Base URL: https://api.brainsait.com/v1

POST /auth/logout             → Revoke tokens

FHIR Resources:
GET  /fhir/Patient/{id}
GET  /fhir/Coverage?patient={id}
POST /fhir/CoverageEligibilityRequest
GET  /fhir/Claim?patient={id}

POST /fhir/ClaimResponse (prior auth)
GET  /fhir/DocumentReference?patient={id}
POST /fhir/DocumentReference

Eligibility:
GET  /eligibility/{memberId}
GET  /eligibility/{memberId}/benefits
GET  /eligibility/{memberId}/service/{code}

Prior Auth:
POST /prior-auth
GET  /prior-auth/{id}
POST /prior-auth/{id}/appeal

AI Services:
POST /ai/chat                 → Basma assistant
POST /ai/prior-auth/predict   → Approval probability
GET  /ai/recommendations/{id} → Health recommendations

Wallet:
GET  /wallet/{memberId}
GET  /wallet/documents/{id}
POST /blockchain/verify

Audit:
POST /audit/events            → Log PHI access
```
